# Windows Island setup

The install clip has a shortened version with installation waits removed. Enable and disable are original, untrimmed recordings. No spoken narration. Descriptions summarize the visible actions.

## Install Island on Windows (1:39)

Open the downloaded Island installer and wait for both Island Browser and Island Desktop to show “Installed successfully.” Select Done, then open Island Browser and sign in with your invited account.

[Watch shortened video](windows-install-short.mp4) · [Full recording](windows-install.mp4)

## Enable Island Desktop (0:56)

Before tasking, open the Windows Start menu, search for Services, and open it. Select Island Background Service and choose Start the service. Wait until its status reads Running. The clip then shows that browsing restrictions are active.

[Watch video](windows-enable.mp4)

## Disable Island Desktop (1:09)

After you finish tasking, open Services, select Island Background Service, and choose Stop the service. Wait for it to stop. The clip then opens another browser to show that the browsing restriction has been lifted. Start the service again before you resume tasking.

[Watch video](windows-disable.mp4)
